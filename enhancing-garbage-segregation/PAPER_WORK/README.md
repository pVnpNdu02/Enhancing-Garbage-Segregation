# PAPER_WORK

- `Resnet50_paperCode.ipynb`: ResNet-50 with a modified classification head on the 6-class dataset, as submitted to ICCCNT 2025. Test accuracy 93.54% on 758 images.
- `VGG16_MODEL.ipynb`: VGG-16 transfer-learning baseline on a separate 7-class dataset (`train/` and `test/` folders, 2,187 training and 564 test images). Test accuracy 58.33% with the frozen base.

Dataset locations expected by the notebooks: `/content/archive (5).zip` (uploaded to Colab) for the ResNet-50 notebook and `/content/drive/MyDrive/CAPSTONE_CNN` for the VGG-16 notebook.

The two notebooks use different datasets and are not directly comparable. The datasets are not included.
